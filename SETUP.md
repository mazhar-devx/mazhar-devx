# How to publish this profile

1. On GitHub create a **public** repo named exactly like your username
   (e.g. `anonymouskh09/anonymouskh09`) and tick "Add a README".
2. Upload everything in this folder (README.md, `assets/`, `.github/`) to the repo root, commit to `main`.
3. Open the repo -> **Actions** -> "Generate contribution snake" -> **Run workflow** once
   (this creates the `output` branch that the snake animation loads from).
4. Delete this SETUP.md and `assets/legacy-banner.png` if you don't want them in the repo.
