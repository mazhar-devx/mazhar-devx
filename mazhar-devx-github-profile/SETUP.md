# How to publish this profile

1. On GitHub create a **public** repo named exactly `mazhar-devx` (same as your username) and tick "Add a README".
2. Upload everything in this folder (`README.md`, `assets/`, `.github/`) to the repo root and commit to `main`.
   (Make sure the hidden `.github/workflows/snake.yml` file is included.)
3. Open the repo -> **Actions** -> "Generate contribution snake" -> **Run workflow** once. This creates the `output` branch the snake animation loads from.
4. Delete this SETUP.md if you don't want it in the repo.
